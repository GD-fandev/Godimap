# GODIMAP v1.1.0

## 日本語

### [GODIMAP v1.1.0をダウンロード](https://github.com/GD-fandev/Godimap/releases/download/v1.1.0/GODIMAP-v1.1.0.zip)

別のPCを含む動作確認が完了したため、GODIMAP v1.1.0をリリースしました。不具合報告と調査にご協力くださった皆様に感謝いたします。

### 主な変更点

- ワールドマップ表示機能と現在地域を示す赤い矢印を追加
- 韓国語・日本語向けの移動コマンドお気に入り機能を追加
- マップ名と座標のOCR範囲を同時に編集できるよう変更
- フィールド、ダンジョン等のマップデータを追加・修正
- OCR認識パターンと一部座標データを修正
- UIおよび3言語の操作説明を更新

### 操作キー

| 操作キー | 機能 |
|---|---|
| `F11` | ワールドマップの表示／非表示 |
| `Shift + F11` | マップ名とX:Y座標のOCR範囲を同時編集 |
| `Ctrl + F11` | 表示中のミニマップまたはワールドマップの位置・サイズ・不透明度を編集 |

### ワールドマップ

`F11`を押すとGodius Clientの中央にワールドマップが表示されます。現在の地域に位置情報が登録されている場合は、赤い矢印でおおよその場所を表示します。位置情報がない地域ではワールドマップだけが表示されます。

![ワールドマップ](https://raw.githubusercontent.com/GD-fandev/Godimap/main/docs/images/v1.1.0/world-map.png)

ワールドマップ表示中に`Ctrl + F11`を押すと、位置・サイズ・不透明度を調整できます。もう一度`F11`を押すと通常のミニマップへ戻ります。

### お気に入り移動コマンド

GODIMAP下部の`お気に入り`から移動先を最大5件まで登録できます。マップ一覧は入力と同時に絞り込まれ、移動先名とオーバーレイに表示する文字も編集できます。

韓国語または日本語で登録すると、同じマップのもう一方の言語情報も同時に仮登録されます。その後の変更は現在選択中の言語だけに反映され、登録順、削除、オーバーレイ位置は両言語で共有されます。

![お気に入りオーバーレイ](https://raw.githubusercontent.com/GD-fandev/Godimap/main/docs/images/v1.1.0/favorites-overlay.png)

ボタンをクリックすると日本語環境では`/MOVE マップ名`がクリップボードへコピーされ、ボタンに一時的に`Copied!`と表示されます。

![コピー完了](https://raw.githubusercontent.com/GD-fandev/Godimap/main/docs/images/v1.1.0/favorites-copied.png)

ゲーム内チャット欄へご自身で貼り付けて使用してください。

![チャット欄への貼り付け](https://raw.githubusercontent.com/GD-fandev/Godimap/main/docs/images/v1.1.0/favorites-paste.png)

本機能は文字列のコピーだけを行い、自動入力、Enterキーの送信、移動コマンドの自動実行は行いません。実際にポータル移動を行うためには、専用アイテムが必要です。

英語名で登録されたマップ名情報が不足しているため、英語環境ではお気に入り機能を利用できません。

### OCR範囲

`Shift + F11`を押すと、マップ名用の赤い範囲とX:Y座標用の黄色い範囲が同時に表示されます。それぞれを個別に移動・サイズ変更し、もう一度`Shift + F11`を押して保存してください。画面全体ではなく、文字だけが入るように小さく設定してください。

### 使用上の注意

- Godiusでは`F11`が標準でヘルプキーに設定されています。ゲーム内オプションでヘルプキーを`H`などへ変更してから使用してください。
- 詳細な操作方法はGODIMAPの`HELP`ボタンから確認できます。
- GodiusとGODIMAPの互換モードおよび管理者権限は同じ状態にしてください。基本的には両方とも管理者権限を無効にすることを推奨します。GodiusをWindows 8互換モードで実行する場合は、GODIMAPにも同じ設定を適用してください。
- ZIPをすべて展開し、`GODIMAP.exe`だけを別の場所へ移動しないでください。デスクトップから使用する場合はショートカットを作成してください。
- 初回起動時にWindowsのセキュリティ警告が表示される場合があります。GitHubの正式なリリースからダウンロードしたファイルであることを確認して実行してください。

## 한국어

### [GODIMAP v1.1.0 다운로드](https://github.com/GD-fandev/Godimap/releases/download/v1.1.0/GODIMAP-v1.1.0.zip)

다른 PC를 포함한 동작 확인을 마쳐 GODIMAP v1.1.0을 배포합니다. 오류 제보와 조사에 협력해 주신 모든 분께 감사드립니다.

### 주요 변경 사항

- 월드맵과 현재 지역을 표시하는 붉은 화살표 추가
- 한국어·일본어용 이동 명령어 즐겨찾기 추가
- 맵 이름과 좌표 OCR 영역 동시 편집
- 필드·던전 등의 맵 데이터 추가 및 수정
- OCR 인식 패턴과 일부 좌표 데이터 수정
- UI 및 3개 언어 조작 설명 갱신

### 조작키

| 조작키 | 기능 |
|---|---|
| `F11` | 월드맵 표시/숨기기 |
| `Shift + F11` | 맵 이름과 X:Y 좌표 OCR 영역 동시 편집 |
| `Ctrl + F11` | 현재 표시 중인 미니맵 또는 월드맵의 위치·크기·불투명도 편집 |

### 월드맵

`F11`을 누르면 Godius Client 중앙에 월드맵이 표시됩니다. 현재 지역에 위치정보가 등록되어 있다면 붉은 화살표로 대략적인 장소를 표시합니다. 위치정보가 없는 지역에서는 화살표 없이 월드맵만 표시됩니다.

![월드맵](https://raw.githubusercontent.com/GD-fandev/Godimap/main/docs/images/v1.1.0/world-map.png)

월드맵 표시 중 `Ctrl + F11`을 누르면 위치·크기·불투명도를 조절할 수 있습니다. `F11`을 다시 누르면 기존 미니맵으로 돌아갑니다.

### 이동 명령어 즐겨찾기

GODIMAP 하단의 `즐겨찾기`에서 이동할 장소를 최대 5개까지 등록할 수 있습니다. 맵 목록은 입력과 동시에 검색되며, 이동할 맵 이름과 오버레이에 표시할 글자도 수정할 수 있습니다.

한국어 또는 일본어에서 등록하면 같은 맵의 반대쪽 언어 정보도 함께 임시 등록됩니다. 이후 수정은 현재 선택한 언어에만 반영되며, 등록 순서, 삭제 및 오버레이 위치는 두 언어가 공유합니다.

![즐겨찾기 오버레이](https://raw.githubusercontent.com/GD-fandev/Godimap/main/docs/images/v1.1.0/favorites-overlay.png)

버튼을 클릭하면 한국어 환경에서는 `/이동 맵이름`이 클립보드에 복사되고 버튼에 잠시 `Copied!`가 표시됩니다.

![복사 완료](https://raw.githubusercontent.com/GD-fandev/Godimap/main/docs/images/v1.1.0/favorites-copied.png)

게임 채팅 입력창에 사용자가 직접 붙여넣어 사용하면 됩니다.

![채팅창 붙여넣기](https://raw.githubusercontent.com/GD-fandev/Godimap/main/docs/images/v1.1.0/favorites-paste.png)

이 기능은 문자열 복사만 수행하며 게임 자동 입력, Enter 자동 전송 및 이동 명령어 자동 실행은 하지 않습니다. 실제로 포탈 이동을 이용하려면 전용 아이템이 필요합니다.

현재 영어 이름으로 등록된 맵 이름 정보가 부족하여 EN 환경에서는 즐겨찾기 기능을 사용할 수 없습니다.

### OCR 영역

`Shift + F11`을 누르면 맵 이름용 붉은 영역과 X:Y 좌표용 노란 영역이 동시에 표시됩니다. 각 영역을 개별적으로 이동·크기 조절하고 `Shift + F11`을 다시 눌러 저장해 주세요. 화면 전체가 아니라 글자만 들어오도록 작게 지정해야 합니다.

### 사용 시 주의사항

- 가디우스에서 `F11`은 기본 도움말 키입니다. 게임 내 옵션에서 도움말 키를 `H` 등으로 변경한 뒤 사용해 주세요.
- 상세 조작법은 GODIMAP의 `HELP` 버튼에서 확인할 수 있습니다.
- 가디우스와 GODIMAP의 호환 모드 및 관리자 권한은 같은 상태로 맞춰 주세요. 기본적으로 양쪽 모두 관리자 권한을 해제하는 것을 권장합니다. 가디우스를 Windows 8 호환 모드로 실행한다면 GODIMAP에도 같은 설정을 적용해야 합니다.
- ZIP 전체를 압축 해제하고 `GODIMAP.exe`만 다른 위치로 옮기지 마세요. 바탕화면에서 사용하려면 바로가기를 만들어 주세요.
- 첫 실행 시 Windows 보안 경고가 나타날 수 있습니다. GitHub 공식 릴리스에서 내려받은 파일인지 확인한 뒤 실행해 주세요.

## English

### [Download GODIMAP v1.1.0](https://github.com/GD-fandev/Godimap/releases/download/v1.1.0/GODIMAP-v1.1.0.zip)

GODIMAP v1.1.0 has been tested, including on another PC, and is now available. Thank you to everyone who reported issues and helped survey map data.

### Main changes

- Added a world map with a red current-region indicator
- Added and corrected field, dungeon, OCR-pattern, and coordinate data
- Combined map-name and coordinate OCR-region editing
- Updated the interface and instructions in three languages

### Hotkeys

| Hotkey | Function |
|---|---|
| `F11` | Show or hide the world map |
| `Shift + F11` | Edit the map-name and X:Y coordinate OCR regions together |
| `Ctrl + F11` | Edit the position, size, and opacity of the current minimap or world map |

### World map

Press `F11` to display the world map in the center of Godius Client. A red arrow indicates the approximate location of the current region when position data is available. Regions without position data display the world map without an arrow.

![World map](https://raw.githubusercontent.com/GD-fandev/Godimap/main/docs/images/v1.1.0/world-map.png)

While the world map is visible, press `Ctrl + F11` to adjust its position, size, and opacity. Press `F11` again to return to the normal minimap.

### OCR regions

Press `Shift + F11` to display the red map-name region and yellow X:Y coordinate region together. Move and resize each region independently, then press `Shift + F11` again to save. Keep each region small and include only the relevant text rather than the entire game screen.

### Important notes

- `F11` opens Help by default in Godius. Change the in-game Help key to another key such as `H` before using GODIMAP.
- Detailed instructions are available from the `HELP` button in GODIMAP.
- Use matching compatibility-mode and administrator settings for Godius and GODIMAP. Running both without administrator privileges is generally recommended. If Godius uses Windows 8 compatibility mode, apply the same setting to GODIMAP.
- Extract the entire ZIP and do not move `GODIMAP.exe` by itself. Create a shortcut if you want to launch it from the desktop.
- Windows may display a security warning on first launch. Confirm that the file came from the official GitHub release before running it.
